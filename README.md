# BeeNeural Data Preprocessing and Visualization

## Objective
Practice data preprocessing, exploratory data analysis (EDA), and visualization using Python.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
Student Performance Dataset with 15 records and 7 columns:
Name, Age, Gender, Study_Hours, Attendance, Math_Score, English_Score.

## Preprocessing
- Inspected dataset structure and data types
- Checked missing values
- Demonstrated missing-value handling using median imputation
- Checked and removed duplicate rows
- Saved the cleaned dataset as CSV

## EDA
Calculated:
- Average study hours
- Average attendance
- Average Math score
- Average English score
- Highest scores
- Correlations with Math score

## Visualizations
- Gender distribution
- Study hours distribution
- Math score distribution
- English score distribution
- Attendance vs Math score
- Study hours vs Math score
- Correlation matrix

## Key Results
- Average Study Hours: 4.87
- Average Attendance: 85.33%
- Average Math Score: 77.17
- Average English Score: 79.20
- Highest Math Score: 95
- Highest English Score: 94

## Note
Correlation values describe relationships observed in this sample and do not establish causation.
